\section{Experiments}
\label{sec:experiments}

This section develops the empirical evaluation protocol. The protocol is specified at the level of design, comparators, metrics, datasets, reporting, and reproducibility outputs. The result tables and figures embedded below use placeholder values and synthetic illustrative curves; they are not observed results. End-to-end runs, numerical values, sensitivity sweeps, and additional ablations will be reported only after the companion experimental implementation is executed.

\subsection{Simulation design}
\label{sec:sim-design}

\input{tables/table_sim_design}

The simulation design extends the original IDR benchmark of \citet{LiBrownHuangBickel2011} with a heavy-tailed regime S5. Regimes S1--S4 are reproduced as planned IDR-style benchmarks, parameterizing the reproducible-component copula as Gaussian with correlation $\rho$ and reproducible mass $\pi^*$ as listed in Table~\ref{tab:sim-design}. Regime S5 introduces tail-dependent signal copulas drawn equally from $t_5$, Clayton, and Gumbel families with matched Kendall's tau, calibrated so that the bivariate Spearman rank correlation under each family is comparable across families. A planned S5-sparse stress-test variant uses $\pi^*=0.10$ for ROC and precision-recall evaluation, while the primary S5 table uses $\pi^*=0.30$.

Each primary regime is evaluated at $K \in \{2,5,10,50\}$ and $n \in \{2{,}000,10{,}000,50{,}000\}$, giving a $5\times4\times3$ factorial design. Each cell is planned for 100 independent Monte Carlo replications with a recorded seed ledger. For every replication, the simulation output will store the true class labels, true cluster assignments, true copula family and parameters, marginal transformations, rank-tie information, and all posterior decision summaries needed to reproduce tables and figures. Marginal distributions are shared Gaussian for S1--S2, heterogeneous Gaussian for S3--S4, skewed or heavy-tailed heterogeneous marginals for S5, and transformed to observed scores before marginal modeling.

\subsection{Comparators}
\label{sec:sim-comparators}

We plan to benchmark against the following comparators using author-recommended default settings where implementation availability, licensing, and input-format compatibility can be verified:
\begin{itemize}[leftmargin=*]
\item \textbf{Vanilla IDR} \citep{LiBrownHuangBickel2011}, applied pairwise across all $\binom{K}{2}$ replicate pairs and aggregated by a pre-specified intersection or consensus rule.
\item \textbf{eCV} \citep{Iakovidis2024eCV}, using the available multi-replicate eCV/IDR-extension implementation after verification of package version and defaults.
\item \textbf{nestedIDR} \citep{Ranalli2026nestedIDR}, using the released implementation if available; otherwise the companion experiment will record the method as a planned comparator requiring author-code verification.
\item \textbf{MaRR} \citep{Philtron2018MaRR}, via the corresponding rank-based implementation if available.
\item \textbf{ChIP-R} \citep{Newell2021ChIPR}, for ChIP-seq and ATAC-seq-style inputs where its assumptions match the data.
\item \textbf{GMCM-AD} \citep{KasaRajan2020GMCM}, for Gaussian mixture-copula comparison with fixed finite mixture size.
\item \textbf{BNP-Archimedean} \citep{PanNietoBarajasCraiu2024}, configured as a methodological neighbor rather than a direct IDR baseline because it models Archimedean copula dependence without the full IDR decision layer.
\item \textbf{PY-IDR (MCMC)}, Algorithm~\ref{alg:mcmc} with planned defaults $H=5$, four overdispersed chains, and posterior summaries reported only after convergence diagnostics are satisfied.
\item \textbf{PY-IDR (VI)}, the finite-truncation structured mean-field approximation of Section~\ref{sec:vi}, with truncation and mini-batch settings recorded in the experiment manifest.
\end{itemize}

\subsection{Metrics}
\label{sec:sim-metrics}

Primary planned metrics are realized FDR at nominal $\alpha=0.05$, power at the same nominal level, posterior contraction in Hellinger distance to the true reproducible-component copula where truth is known, area under the ROC curve, area under the precision-recall curve, and calibration of posterior local-idr thresholds against realized FDR. Secondary metrics are wall-clock time, effective sample size per second, posterior split-$\widehat R$, number of active clusters, posterior mass on the correct cluster count, local-idr credible-band calibration, and decision stability across seeds. Every Monte Carlo table will report means with Monte Carlo standard errors or uncertainty bands, and every calibration plot will report the number of replications used. Planned posterior predictive checks include marginal rank calibration, pairwise Kendall/Spearman diagnostics, posterior predictive cluster-size distributions, and failure-case summaries for empty or near-empty rejection sets.

\subsection{Ablations and sensitivity analyses}
\label{sec:sim-sens}

We plan sensitivity analyses for the LKJ shape $\eta\in\{1,2,5\}$, auxiliary-atom count $H\in\{1,3,5,10\}$, Bernstein-degree grid, and prior on the reproducible mass $\pi$. Additional planned ablations isolate the contribution of each PY-IDR component: PY versus DP prior, Gaussian-only versus heavy-tail atom base, empirical-rank approximation versus learned marginals, exchangeable versus factor-structured correlation classes, MCMC versus VI inference, and pairwise aggregation versus joint $K$-replicate modeling. Planned stress tests include weakly dependent irreproducible components, high tie rates, missing replicates, near-singular correlation structures, high-dimensional $K$, and marginal misspecification. These ablations are experimental tasks, not completed results.

\subsection{Real-data evaluation}
\label{sec:real}

\input{tables/table_datasets}

The five datasets summarized in Table~\ref{tab:datasets} span the principal planned application domains of multi-replicate IDR. For every dataset, the coding agent must produce a data manifest, feature-universe definition, replicate-matching file, score column dictionary, tie and missingness policy, rank-transformation output, and dataset-specific QC summary before fitting any model.

\paragraph{ENCODE 4 CTCF ChIP-seq.}
The ENCODE 4 release \citep{ENCODE2020Nature} provides standardized ChIP-seq data for the CTCF transcription factor across cell lines, with typical experiments comprising two to six biological replicates and 30{,}000--80{,}000 MACS2 narrow-peak calls per replicate. The planned analysis applies PY-IDR to each multi-replicate experiment, with replicate-aware peak signal scores transformed to ranks before model fitting. Planned outputs are per-peak posterior local idr, reproducible-peak count at IDR $\leq0.05$, and posterior summaries of active dependence regimes. Planned baselines are pairwise vanilla IDR aggregation, eCV, nestedIDR if available, ChIP-R, and MaRR.

\paragraph{ENCODE 4 ATAC-seq.}
ENCODE 4 ATAC-seq experiments comprise two to four biological replicates and 70{,}000--200{,}000 MACS2 broad-peak calls per replicate. The planned setup mirrors CTCF, with additional attention to heavier-tailed score distributions and platform effects across cell lines. Any claim that PY-IDR recovers more peaks than ChIP-R is a planned hypothesis until the analysis is run.

\paragraph{DREAM5 gene-network challenge.}
The DREAM5 challenge \citep{Marbach2012DREAM5} provides ranked predictions from 35 algorithms across reference networks. Replicates here are algorithms rather than biological replicates; the IDR framework provides a planned way to aggregate algorithm predictions into a community-consensus reproducible network. Planned outputs include reproducible-edge counts at IDR $\leq0.05$ and overlap with available gold-standard edges.

\paragraph{Tabula Muris pseudobulk.}
Tabula Muris \citep{TabulaMuris2018} is a single-cell mouse atlas with two sequencing technologies. The planned analysis constructs pseudobulk replicates by aggregating cells within tissue and technology, then applies PY-IDR to identify reproducible differential-expression signatures while modeling technology-specific marginal distributions.

\paragraph{Pan-UKBB GWAS.}
The Pan-UK Biobank resource \citep{Bycroft2018UKB,Karczewski2024PanUKBB} provides ancestry-stratified GWAS summary statistics across multiple ancestry groups and thousands of traits. The planned PY-IDR analysis uses ancestry-specific $z$-scores as replicate-like inputs for selected phenotypes, with $K=6$ ancestry strata when all groups pass QC. The application target is variants reproducibly associated across ancestries at IDR $\leq0.05$; any comparison against EUR-only thresholding is a planned analysis rather than an observed result in this manuscript.
